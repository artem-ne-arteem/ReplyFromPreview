# Reply from Preview

Прототип фичи для Telegram iOS: ответ прямо из превью чата, без открытия самого чата.

## Что умеет
- Долгий тап по чату: превью «вырастает» из строки, фон размывается, слышен тактильный отклик.
- Под превью есть поле ввода и меню (Mark as Unread / Pin / Mute / Delete).
- Тап по полю: меню уезжает, превью растягивается над клавиатурой.
- Отправка: сообщение въезжает в чат, чат становится прочитанным и поднимается наверх, превью «улетает» в его строку.
- Тап по шапке превью открывает полный чат, тап по фону, кнопка «назад» или свайп шапки вниз закрывают превью.

## Как запустить (нужен Mac с Xcode 16+)
1. Xcode → File → New → Project → iOS → App. Interface: SwiftUI, имя: `ReplyFromPreview`.
2. Удали из проекта `ContentView.swift` и созданный Xcode файл `ReplyFromPreviewApp.swift`.
3. Перетащи в проект 5 файлов из папки `ReplyFromPreview/` (галочка «Copy items if needed»).
4. В настройках таргета поставь Minimum Deployments: **iOS 17.0**.
5. Выбери симулятор iPhone или свой телефон и нажми ▶️ (Cmd+R).

Без Mac: на iPad в **Swift Playgrounds** создай App и добавь туда те же файлы.

## Видео для конкурса
Запускай на реальном iPhone (так видна настоящая клавиатура и анимации на 120 Гц) и записывай экран через Пункт управления.
